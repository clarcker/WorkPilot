## 预期结论（填数后修订）

- CPU 7B 在 `llm_max_concurrency_local=2` 下，第 3 路起应出现 `queued`，`llm_queue_timeout` 后 SSE `error: 系统繁忙`
- 外部 API 在 8 并发内通常 TTFT 可接受；更高并发看限流与熔断
- P95 检索阶段可从 `agent_traces.steps[retrieve_docs].latency_ms` 汇总
