## 一、RAG 工作流（LangGraph 节点图）

```
用户输入
    │
    ▼
┌─────────────────┐
│  preprocess     │  清理输入、载入会话历史、构建上下文
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ classify_intent │  LLM 判断意图
└────────┬────────┘
         │
    ┌────┴──────────────────┐
    │                       │
    ▼                       ▼
闲聊 / 超出范围          知识库查询
    │                       │
    ▼                       ▼
┌──────────────┐   ┌─────────────────┐
│ direct_reply │   │  retrieve_docs  │  向量检索 + 权限过滤
└──────────────┘   └────────┬────────┘
                            │
                  ┌─────────┴──────────┐
                  │                    │
                  ▼                    ▼
             有相关文档           无相关文档
                  │                    │
                  ▼                    ▼
        ┌──────────────────┐  ┌──────────────────┐
        │ generate_answer  │  │ fallback_reply   │  告知无相关内容
        │ LLM 生成 + 引用  │  └──────────────────┘
        └────────┬─────────┘
                 │
                 ▼
        ┌─────────────────┐
        │  record_trace   │  写入 trace + 审计日志
        └────────┬────────┘
                 │
                 ▼
           SSE 流式输出
```

---

## 二、节点职责说明

| 节点 | 由谁处理 | 说明 |
|---|---|---|
| preprocess | 代码 | 截断超长输入、拼接最近 N 条历史消息 |
| classify_intent | LLM | 输出：`knowledge_query` / `chitchat` / `out_of_scope` |
| retrieve_docs | 代码 | pgvector top-k，SQL 层过滤当前用户无权限的文档 |
| generate_answer | LLM | Prompt 带检索片段，输出答案 + citations |
| fallback_reply | 代码 | 固定话术，不走 LLM |
| direct_reply | LLM | 闲聊走轻量回复，超出范围礼貌拒答 |
| record_trace | 代码 | 每个节点耗时、输入输出写入 DB |

## 三、用户用例

### UC-01 普通员工

| # | 用例 | 触发 | 主流程 |
|---|---|---|---|
| 1 | 查询制度文档 | 员工提问"报销住宿上限是多少？" | 走 RAG 全流程，返回答案 + 文档来源 |
| 2 | 多轮追问 | 员工继续问"那出差补贴呢？" | preprocess 拼接历史，继续检索 |
| 3 | 查看历史会话 | 员工打开历史记录页 | 读取个人 conversations 列表 |
| 4 | 修改密码 / 昵称 | 员工进入个人设置 | 直接更新 users 表 |

### UC-02 部门管理员

| # | 用例 | 触发 | 主流程 |
|---|---|---|---|
| 5 | 上传文档 | 管理员上传 .md/.docx/.pdf | 解析 → 分块 → embedding → 写入 pgvector，状态实时更新 |
| 6 | 配置文档权限 | 管理员设置文档可见范围 | 更新 documents 表权限字段，检索时自动过滤 |
| 7 | 查看员工对话日志 | 管理员查看本部门提问记录 | 读取 conversations，限定 dept_id |
| 8 | 创建员工账号 | 管理员新增员工 | 生成用户名、随机密码，写入 users 表 |

### UC-03 超级管理员

| # | 用例 | 触发 | 主流程 |
|---|---|---|---|
| 9 | 创建部门管理员 | 超管新增管理员账号 | 同 UC-08，额外绑定部门 |
| 10 | 查看审计日志 | 超管进入审计日志页 | 读取 audit_logs 表，不可删除 |
| 11 | 系统配置 | 超管修改模型 / 对话上限等 | 更新 system_config 表 |
