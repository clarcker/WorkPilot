## 三、失败用例分析

| 测试 | 错误 | 说明 |
|---|---|---|
| `test_update_document_metadata` | MissingGreenlet | `PATCH /api/docs/{id}` 接口中存在 lazy load 问题 |

**错误信息：**
```
sqlalchemy.exc.MissingGreenlet: greenlet_spawn has not been called; 
can't call await_only() here.
```

**修复建议：**
与之前 auth 模块的 MissingGreenlet 相同修复方式 - 使用 `selectinload` 或手动查询关联数据。
