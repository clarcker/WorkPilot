# 销售部差旅补充规定

版本 v1.0 | 生效日期 2026-02-01 | 归口部门：销售部（dept_only）

## 一、适用范围

仅适用于销售部外勤人员的客户拜访差旅，不替代公司《报销管理制度》中与本规定冲突的条款以外内容。

## 二、住宿标准（销售特批）

| 场景 | 住宿上限（元/人/晚） |
|---|---|
| 客户所在一线城市 | 450 |
| 二线城市 | 350 |
| 展会期间（需提前备案） | 600 |

销售总监及以上职级可上浮 20%。

## 三、客户招待费

- 工作餐招待：人均不超过 150 元，需注明客户单位与人数
- 娱乐性支出一律不予报销
