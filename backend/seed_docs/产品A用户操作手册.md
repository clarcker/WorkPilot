# 产品 A 用户操作手册

版本 v3.4 | 归口部门：产品部

## 一、安装与登录

1. 从内部软件中心下载安装包
2. 使用企业邮箱账号登录
3. 首次登录强制修改密码

## 二、核心功能

### 2.1 任务创建

点击「新建任务」，填写标题、负责人、截止日期。支持附件与富文本描述。

### 2.2 进度跟踪

看板视图支持拖拽流转：待办 → 进行中 → 待验收 → 已完成。

### 2.3 报表导出

报表中心支持按项目、成员、时间维度导出 Excel。

## 三、常见问题

- 无法登录：确认是否连接 Corp-Office 网络
- 数据不同步：退出重新登录或联系 IT 提工单
