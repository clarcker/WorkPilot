# IT 设备与运维服务规范

版本 v2.0 | 生效日期 2026-01-15 | 归口部门：信息技术部

## 一、设备配置标准

按岗位序列配置办公设备，原则上每 4 年更换一次：

| 岗位类型 | 标准配置 |
|---|---|
| 研发岗 | 16 英寸笔记本（32G 内存 / 1T 固态）+ 27 寸显示器 ×1 |
| 设计岗 | 16 英寸笔记本（32G 内存）+ 色彩管理显示器 ×1 + 数位板 |
| 职能岗 | 14 英寸笔记本（16G 内存 / 512G 固态） |
| 销售岗 | 14 英寸轻薄本 + 移动热点设备 |

有特殊性能需求的，由部门负责人提交书面说明，经信息技术部评估后特批。

## 二、设备申领流程

1. 在 IT 服务平台提交设备申领单，注明用途与配置需求
2. 部门负责人审批
3. 信息技术部核查库存，有库存的 **2 个工作日内**发放；无库存的进入采购流程，周期约 15 个工作日
4. 领用时签署《设备使用责任书》，设备资产编号绑定至个人

离职或转岗时须归还全部设备，经检验合格后方可办理离职手续。

## 三、设备维修申请

设备出现故障时，按以下方式申请维修：

1. **提交工单** — 在 IT 服务平台或企业微信「IT 服务」入口提交维修工单，填写故障现象、资产编号、紧急程度
2. **响应时限** — 一般故障 4 小时内响应，紧急故障（影响业务连续性）1 小时内响应
3. **处理方式** — 可现场处理的当场解决；需送修的由信息技术部统一送厂，并提供备用机
4. **备用机** — 送修期间提供同级或降级备用机，最长借用 30 天

**费用承担：**

- 正常使用产生的故障，维修费用由公司承担
- 人为损坏（进液、跌落、私自拆机等）的，视情况由个人承担 30%–100% 维修费用
- 设备遗失的，按残值折算赔偿

## 四、常见故障自助排查

**网络连不上：**
1. 确认 Wi-Fi 已连接到 `Corp-Office`，而非访客网络
2. 尝试断开重连，或重启网络适配器
3. 检查是否需要重新登录网络认证页面
4. 以上无效则提交 IT 工单，注明所在工位号

**打印机无法打印：** 确认已连接办公网络、打印队列无卡住任务、纸张与硒鼓状态正常。

**系统账号被锁定：** 连续 5 次密码错误将锁定 30 分钟，可提交工单申请立即解锁。

## 五、软件安装

公司统一采购的软件通过内部软件中心自助安装。需安装非清单内软件的，须提交申请并说明用途，禁止安装未授权或来源不明的软件。
